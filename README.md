### Interaction contract

1. Scrub the range input, tap a chronological list item, or use the timeline
   markers. The world title, date, source anchor, visual treatment, status, and
   relationship panel change together.
2. Play/pause evolution to move through the worlds. The control is a real
   state transition and respects both the system reduced-motion preference and
   the explicit `reduce motion` control.
3. Hold the selected moment. The browser-local versioned record restores after
   reload and exposes `Reopen archived study`, which routes to the immutable
   former lab at `archive/2026-07-31-universe-v1/`.
