## Run 14 · 10 Aug 2026

### Falsifiable hypothesis

If a one-thumb chronological transport lets an artist scrub synthetic
experiments, play/pause an evolving visual world, hold a selected moment, and
reopen its archived route, the purpose of the lab becomes understandable and
revisitable without a spatial-map explanation.

This contrasts run 13's source-backed Live Session capture/compare/select loop:
the primary action is now time and visual evolution, not another capture
surface. The source remains synthetic and authoritative; the timeline is an
interpretation layer.

### Interaction contract

1. Scrub the range input, tap a chronological list item, or use the timeline
   markers. The world title, date, source anchor, visual treatment, status, and
   relationship panel change together.
2. Play/pause evolution to move through the worlds. The control is a real
   state transition and respects both the system reduced-motion preference and
   the explicit `reduce motion` control.
3. Hold the selected moment. The browser-local versioned record restores after
   reload and exposes `Reopen archived study`, which routes to the immutable
   former lab at `archive/2026-07-31-universe-v1/`.

### Provenance and accessibility

All songs, dates, source filenames, lyrics, chords, statuses, relationships,
and visual worlds are synthetic fixtures. No audio, video, private media,
account state, credentials, generated binary media, or authenticated
persistence is bundled. The transport is keyboard/touch friendly, visible
focus is retained, and reduced motion is honored through both the system
preference and the explicit control.
